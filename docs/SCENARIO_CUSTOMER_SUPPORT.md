# 안건 ① — 고객의 기다림을 줄여라

> **v0.8 적용:** [임원 에이전트 명세](AGENT_BOARDROOM_SPEC.md)를 먼저 적용한다. 이 파일의 자료·추천 문구·조건 확인·원안 정규화는 live/scripted 공통이다. 고정 반응·표결 우선순위·대표 경로의 득표수는 scripted 테스트 데이터이며 live 에이전트의 정답이나 강제 표가 아니다. live는 동일 최종안과 실제 논의로 각 임원이 판단한다.

버전 1.1 · 2026-09-09 · P1 구현 기준. 모든 자료·대사·규칙은 체험용 가상 설정이며 실제 삼성화재 자료나 의결 규정이 아니다. 현장 리허설 후 조정할 수 있다.

## 브리핑

원안 `customer-support-original`: 일반 안내와 복잡한 보장 문의까지 AI가 자동 답변하는 서비스를 도입한다. 연계 범위·담당자 이관·데이터 사용·품질 기준은 미정이다.

의장: “기다림을 줄이면서 잘못된 안내도 막을 수 있을까요? 특별 이사님의 의견을 듣겠습니다.”

| ID | 자료 카드 | 가상 내용 |
| --- | --- | --- |
| E1 | 현장 의견 | 반복 일반 안내의 초안 작성에 시간이 든다. 실제 대기시간 개선 수치는 아직 없다. |
| E2 | 시험 메모 | 일반 안내에는 도움이 됐으나 복잡한 보장 판단에서 오류가 발견됐다. 전체 문의 자동화의 품질은 입증되지 않았다. |
| E3 | 시범 운영 여건 | 한 개 상담 팀에서 시험할 수 있다. 시스템 연계 범위와 담당자 이관 절차는 미정이다. |
| E4 | 검토 메모 | 고객정보 사용·접근·공유 조건과 처리시간·답변 품질 평가 기준을 정해야 한다. |

BRIEFING 자동 AI 정리 카드: “반복 일반 안내의 초안 지원 수요는 있습니다(E1). 복잡한 보장 판단 오류가 있어 자동 답변 범위를 나눠야 합니다(E2). 한 팀에서 시험할 수 있지만 이관 절차(E3), 데이터 조건과 품질 기준(E4)은 추가 확인이 필요합니다.”

자료 4장 옆 상시 표시, ‘체험용 사전 구성’ 표기와 E1~E4 근거 연결을 제공한다. 클릭이나 실제 모델 연결은 필요하지 않다. 효과 수치·자료에 없는 사실은 생성하지 않는다.

## 초기 임원 의견

표 아이콘이나 찬반 선택 UI 없이 아래 검토 의견을 표시한다.

| 인물 | 발언 | 근거 |
| --- | --- | --- |
| CEO | 일반 안내의 기다림을 줄일 기회를 검토합시다. | E1 |
| CFO · CAIO | 한 팀에서 처리시간·수정량과 비용을 먼저 확인합시다. | E3, E4 |
| CIO | 복잡한 문의의 이관과 공유 전 검토 절차가 필요합니다. | E2, E3 |
| CISO | 고객정보의 사용·접근 조건부터 정해야 합니다. | E4 |

## 추천 문구와 구조화 조건

| 문구 ID | 문장 | 조건 ID |
| --- | --- | --- |
| P1 | 일반 안내·한 개 팀의 파일럿부터 시작합시다. | LIMITED_PILOT |
| P2 | 답변 초안은 직원이 검토하고 복잡한 보장 문의는 담당자에게 이관합시다. | ESCALATE_REVIEW |
| P3 | 사용·접근·공유 조건을 확인한 고객정보만 활용합시다. | DATA_ACCESS |
| P4 | 처리시간과 답변 수정량·오류를 확인한 뒤 확대합시다. | QUALITY_GATE |
| P5 | 복잡한 보장 문의도 직원 검토 없이 자동으로 확답합시다. | AUTO_ALL |
| P6 | 보장 판단 오류와 데이터 조건의 검증 자료를 더 요청합시다. | 없음; 요청 의견으로 기록 |

ID는 scenarioId로 구분한다. P6의 검증 요청을 최종 HOLD 표로 추정하지 않는다. `ESCALATE_REVIEW`와 `AUTO_ALL`는 동시 확정 불가다. 충돌하면 두 문구를 함께 보여주고 사용자가 유지할 조건을 고르게 한다. 취소 시 기존 입력을 보존한다. 다른 조건은 함께 제안 가능하나 아래 우선순위에 따라 즉시 확대/자동화 조건의 우려가 우선한다.

최종 제출 텍스트를 바탕으로 허용 조건을 제안하고 참가자가 확인한다. 부정문·상충 표현을 단순 키워드로 자동 채택하지 않는다. 이해하지 못한 입력도 원문으로 기록하고 조건 없이 진행할 수 있다. 후속 입력 시 누적 조건의 유지·해제를 확인한다. 조건 확정과 최종 투표는 별도다.

## 조건별 반응과 후속 질문

| 확인 조건 | 반응 |
| --- | --- |
| LIMITED_PILOT | CFO·CAIO: “일반 안내 한 팀으로 시범 투자 범위를 정하겠습니다.” |
| ESCALATE_REVIEW | CIO: “공유 전 검토와 보장 문의 이관 절차를 수정안에 넣겠습니다.” |
| DATA_ACCESS | CISO: “데이터 조건을 기록하겠습니다. 실제 권한 검증은 착수 전에 필요합니다.” |
| QUALITY_GATE | CFO·CAIO: “처리시간·수정량·오류를 확대 판단 기준으로 삼겠습니다.” |
| AUTO_ALL | CIO: “오류가 발견된 보장 판단까지 검토 없이 자동화하는 데 반대합니다.” |
| 없음 | CEO: “확인 요청을 기록했습니다. 수정 조건이 없으면 원안으로 심의하겠습니다.” |

후속 질문(가정, 최대 1회): “고객이 보장 여부를 지금 확답해 달라고 하면 어떻게 처리할까요?”

- “담당자에게 이관하고 검토한 뒤 안내합시다.” → ESCALATE_REVIEW 추가 제안. 충돌하는 기존 조건이 있으면 유지/해제를 본인이 확인한다.
- “직원 검토 없이 AI가 바로 확답합시다.” → AUTO_ALL 추가 제안; ESCALATE_REVIEW가 있으면 충돌 확인 후 하나만 확정한다.
- “앞선 의견을 유지하겠습니다.” → 조건 변경 없음.
- 직접 입력 → 동일한 원문 보존·허용 조건 확인 흐름.

최종 안건은 원안과 확인된 조건 전체를 표시한다. 조건 하나 이상이면 수정안이며, 조건 채택은 검증 완료를 뜻하지 않는다. MOTION에서 확인 후 VOTE 진입 시 motionId와 조건을 고정한다. 모든 의석은 같은 안건을 보고 투표한다.

## 가상 임원 표결 규칙

임원별 위에서 처음 일치하는 행 하나를 적용한다. 참가자 표나 LLM 출력은 규칙의 입력이 아니다.

| 임원 | 우선순위 조건 | 최종 표 |
| --- | --- | --- |
| CEO | AUTO_ALL 있음 | HOLD |
| CEO | 나머지 | YES |
| CFO·CAIO | AUTO_ALL 있음 | NO |
| CFO·CAIO | LIMITED_PILOT 및 QUALITY_GATE 있음 | YES |
| CFO·CAIO | 나머지 | HOLD |
| CIO | AUTO_ALL 있음 | NO |
| CIO | ESCALATE_REVIEW 있음 | YES |
| CIO | ESCALATE_REVIEW 없음 | NO |
| CISO | AUTO_ALL 있음 | NO |
| CISO | DATA_ACCESS 및 ESCALATE_REVIEW 있음 | YES |
| CISO | DATA_ACCESS 있음 | HOLD |
| CISO | 나머지 | NO |

CISO는 정보 사용 조건과 검토 절차가 함께 포함되면 착수 전 실제 권한 검증을 전제로 찬성한다. 파일럿·측정 문구의 개수를 찬성 기준으로 삼지 않는다. 반응: “정보 사용 조건과 검토 절차를 갖춘 안건에 찬성합니다. 실행 전 권한 검증은 필요합니다.” 다른 임원도 운영·투자 우려를 유지할 수 있다.

## 결과 기록과 검증

- 가결·보류·부결 모두 정상 엔딩이다. 내 원문·실제 채택 조건·소수 의견·최종 표를 기록한다. 채택되지 않은 조건이나 미확정 표를 채우지 않는다.
- 내 표의 영향은 임원 네 표와 안건을 고정한 상태에서 비교한다. 의견으로 조건이 달라진 영향과 한 표의 영향을 구분한다.
- 남은 과제 후보: 고객정보 권한 검증, 검토·이관 담당자 지정, 파일럿 답변 품질과 처리시간 측정. 실제 남은 항목만 표시하며 절차가 채택돼도 이행 완료라고 쓰지 않는다.
- 자동 자료 정리 표시 이벤트가 있는 정상 완주 결과에 ‘자료 4장 자동 정리 데모 표시’를 항상 포함한다. 추가 도움 미사용은 별도로 표시한다. 실제 모델 호출과 사전 구성을 구분한다.
- 추가 AI 도움은 E1~E4를 근거로 의견 공통점, 원안/확인 조건 차이, 내 발언 정리만 제공한다. 사실·효과·표를 생성하지 않는다.
- 입력300자·편집 보존·충돌 확인·시간240초·무입력90초·세션 초기화·늦은 응답은 [구현 지시서](../CLAUDE_IMPLEMENTATION.md)를 따른다. 무입력 복귀는 결과 집계 없이 세션을 폐기한다.
- 대표 경로뿐 아니라 허용 조건 조합×참가자 YES/HOLD/NO/UNCAST를 검사한다. 각 임원 규칙의 총괄성, 5표 유지, 찬성·반대 양쪽 결정 경로, 결론 불변 경로를 검증한다.
