## 확정 방향 요약(캔버스 메모 그대로)

C안 요약(확정 방향)
· 왼쪽 무대(A): 시안 브래킷·스캔라인·CAM 판독 라벨, 어두운 명패에 역할색 테두리, 직함(CEO·CFO·CAIO·CISO) + 역할 한 단어 + 표정 배지
· 오른쪽·CTA·로그(B): 종이 서류철 패널, 타자기 라벨, 붉은 스탬프, 앰버 CTA
· 구성(A): 01~05 단계 탭, SITREP·PROPOSAL·UNKNOWN, YOUR ORDERS, EXHIBIT 2열, TRANSCRIPT 로그, DEBRIEF 집계 막대
· 도장: 결과 화면 오른쪽 종이 보고서 우상단에 잉크 도장(가결·부결 = 붉은 잉크, 설득 성공 = 앰버 잉크). 무대에는 표 배지만
· 도장은 종이 보고서 오른쪽 전용 칸(200px)에 — 문서 글자와 겹치지 않음. 미획득 시 점선 한 줄 'BONUS 미획득 · 같은 표 n석 · 3석부터'(부결 장)
· 결과 보고서 화면은 두지 않음(2026-09-29 결정). 결과 화면의 '회의록 전문 보기'가 오른쪽 열을 전문 패널(내부 스크롤)로 바꾸고 다시 요약으로 돌아올 수 있음
· 말풍선은 줄 수 자르기 유지, 전문은 TRANSCRIPT에
· 구현: 토큰 2계열(무대 시안 HUD / 본문 종이·앰버) + 서체 2종 + 스탬프·브래킷 CSS. 레이아웃·동작 불변. 작업량 M

## 바뀌지 않는 규칙

- 무대 말풍선은 줄 수로 자른다(1920 3줄·≤1280 2줄). 전문은 발언 흐름(TRANSCRIPT) 패널에.
- 명패는 직함(CEO·CFO·CAIO·CISO). 코드네임은 쓰지 않는다.
- 도장은 결과 화면 오른쪽 종이 보고서의 전용 칸에만. 무대에는 표 배지만(무대 우하단 도장 규칙 폐기).
- 결과 보고서 화면은 두지 않는다(T58은 결과 화면의 "회의록 전문 보기" 패널).
