# 안건 후보 — 행사 TF 검토용

버전 1.0 · 2026-09-22 · 근거: `AX_Day_2026_Boardroom_Plan.md` 1·5절, `docs/AGENT_BOARDROOM_SPEC.md` 2장, `docs/SCENARIO_AI_ASSISTANT.md`(안건 구조 기준)

이 문서는 BOARDROOM 2026 부스의 세 안건을 고르기 위한 검토표다. 후보와 기준, 지금까지 걸러낸 이력을 한자리에 모았다. 결정은 TF 미팅에서 하고 5절에 기록한다.

## 0. 미팅에서 쓰는 법

1. 1절의 5개 관문을 먼저 합의한다. 관문을 바꾸면 후보 판정도 바뀐다.
2. 2절 후보표에서 **현황 확인란**을 먼저 채운다 — 이미 시행 중이거나 정책으로 막혀 있으면 그 자리에서 탈락이다.
3. 남은 후보로 3절의 조합을 고른다. 축이 겹치지 않는 세 개여야 한다.
4. 결정과 보류 사유를 5절에 적는다.

## 1. 안건이 통과해야 하는 5개 관문

부스 구조상 네 임원이 모두 할 말이 있어야 하고, 참가자가 4분 안에 판단할 수 있어야 한다.

| 관문 | 확인 질문 | 못 지키면 |
| --- | --- | --- |
| CEO | 회사의 방향·이미지·구성원 사기에 닿는가 | 의장이 진행만 하는 인물이 된다 |
| CFO | 셀 숫자와 서로 어긋나는 수치 2개가 있는가 | 비용 발언이 공허해진다 |
| CAIO | 운영·연계·구현 부담을 말할 거리가 있는가 | 좌석 하나가 비게 된다 |
| CISO | 출입·기밀·개인 기록 중 하나가 걸리는가 | 없는 우려를 지어내 자료 밖 사실이 생긴다 |
| 구조 | 상충 조건쌍이 있고 승인·보류·부결 세 엔딩이 모두 납득되는가 | 정답 있는 퀴즈가 된다 |
| **현황** | **이미 시행 중이거나 정책으로 막혀 있지 않은가** | 참가자가 "이미 하는데요?"로 받는다 |

> 안건 주제가 AI일 필요는 없다. AI 체감은 임원 4명이 실제 AI라는 점과 AI 비서실장의 자료·발언 정리가 담당한다(`AX_Day_2026_Boardroom_Plan.md` 1절). 다만 CAIO는 직함이 AI총괄이므로, AI가 아닌 안건에서는 "운영·구현" 쪽으로 판단 기준을 넓히는 작업이 필요하다(T35 범위).

## 2. 후보 6개

### 2-1. 사내 게시판 익명제

- **핵심 갈등**: 솔직함과 책임 · **성격**: 익명성 설계
- **상충 조건쌍**: "완전 익명 — 작성자 추적 불가" ↔ "문제 발생 시 관리자가 추적 가능"
- **조건 후보**: 시범 게시판부터 / 게시 전 검수 / 신고 3회 시 블라인드 / 임원 열람 제한 / 로그 보관 기간 명시 / 운영 효과 측정
- **세 엔딩**: 승인 → 글은 늘었으나 익명 뒤 비방도 늘었다 / 보류 → 한 게시판에서 시범 / 부결 → 실명 유지, 목소리는 여전히 밖으로

| 역할 | 할 말 |
| --- | --- |
| CEO | 솔직한 목소리가 올라오는가 vs 조직 신뢰가 상하는가 |
| CFO | 모니터링 인력·검토 공수, 게시글 월 320건 / 140건(상충 수치) |
| CAIO | 익명 처리·중복 계정 차단 구현, 계정 체계 연계 |
| CISO | 익명성과 추적 가능성의 경계, 로그 보관 기간 |

- 판정: ◎ (4역할 전부 강함)
- [ ] 현황 확인: 이미 시행 중인가 / 정책상 가능한가

### 2-2. 회의 30분 상한제

- **핵심 갈등**: 효율과 충분한 논의 · **성격**: 회의 규칙
- **상충 조건쌍**: "전 회의 30분 강제 종료" ↔ "주요 회의는 예외 허용"
- **세 엔딩**: 승인 → 회의는 짧아졌으나 복도에서 다시 모인다 / 보류 → 일부 부서 시범 / 부결 → 그대로

| 역할 | 할 말 |
| --- | --- |
| CEO | 회의 문화, 의사결정 속도 |
| CFO | 회의 시간의 인건비 환산 |
| CAIO | 예약 시스템 자동 종료 구현 |
| CISO | 회의록 보관·공유 범위 |

- 판정: ○ — **CISO가 약하다.** 안건에 "회의록을 어떻게 남기고 누구까지 볼까"를 조건으로 넣어야 네 좌석이 다 산다.
- [ ] 현황 확인

### 2-3. 대면 보고 폐지

- **핵심 갈등**: 의사결정 속도와 소통 깊이 · **성격**: 보고 관행
- **상충 조건쌍**: "대면 보고 원칙 폐지" ↔ "주요 안건은 대면 유지"
- **세 엔딩**: 승인 → 보고는 빨라졌으나 맥락이 빠진다 / 보류 → 일부 보고만 전환 / 부결 → 그대로

| 역할 | 할 말 |
| --- | --- |
| CEO | 의사결정 속도와 현장 감각 |
| CFO | 보고 준비 시간 vs 결정 지연 건수 |
| CAIO | 문서 유통·이력 관리 체계 |
| CISO | 보고 문서의 배포·보관 범위 확대 |

- 판정: ○
- [ ] 현황 확인

### 2-4. 종이 없는 사무실 (출력 총량 상한)

- **핵심 갈등**: 전환 효과와 현장 부담 · **성격**: 문서 규칙
- **상충 조건쌍**: "부서별 출력 총량 상한" ↔ "상한 없이 권고만"
- **세 엔딩**: 승인 → 출력은 줄었으나 개인 기기 저장이 늘었다 / 보류 → 일부 부서 시범 / 부결 → 그대로

| 역할 | 할 말 |
| --- | --- |
| CEO | 일하는 방식의 상징 |
| CFO | 출력비·보관 공간 vs 전환 비용 |
| CAIO | 전자문서 체계 전환 부담 |
| CISO | 전자문서 접근 권한 재설계 |

- 판정: ○ — 재미와 편 갈림이 여섯 중 가장 약하다. **이미 상당 부분 전자화돼 있을 가능성이 높아 현황 확인이 가장 급한 후보다.**
- [ ] 현황 확인

### 2-5. 콘도 성수기 배정 규칙

- **핵심 갈등**: 형평과 만족 · **성격**: 자원 배분
- **상충 조건쌍**: "과거 이용자 감점" ↔ "매회 완전 무작위"
- **자료 예시**: 객실 40 vs 신청 260 / 특정 부서 편중 34%·11%(상충) / 3년 연속 이용자 12명
- **세 엔딩**: 승인 → 신규 이용자는 늘었으나 운 나쁜 사람은 계속 운이 나쁘다 / 보류 → 다음 시즌 시범 / 부결 → 선착순 유지

| 역할 | 할 말 |
| --- | --- |
| CEO | 형평과 구성원 사기 |
| CFO | 객실 비용, 신청 대비 정원 |
| CAIO | 배정 시스템·이력 데이터 정합성 |
| CISO | 신청·이용 기록 보관과 열람 범위 |

- 판정: ○ — 가족·근속 데이터는 쓰지 않는다(노무 논쟁으로 번진다). 이용 이력·신청 시각·부서 분산만 쓴다.
- [ ] 현황 확인

### 2-6. 멘토링 짝 정하기

- **핵심 갈등**: 자율과 매칭 품질 · **성격**: 프로그램 운영
- **상충 조건쌍**: "본인 신청 자율 매칭" ↔ "회사가 배정"
- **세 엔딩**: 승인 → 매칭 수는 늘었으나 "왜 저 사람과" 문의가 늘었다 / 보류 → 자원자 한정 시범 / 부결 → 수작업 유지

| 역할 | 할 말 |
| --- | --- |
| CEO | 인재 육성 |
| CFO | 담당자 공수, 운영 예산 |
| CAIO | 매칭 운영 부담 |
| CISO | 프로필 열람 범위, 매칭 근거 공개 여부 |

- 판정: ○ — **CFO가 약하다.** 운영 예산·외부 프로그램 위탁비를 자료에 넣어야 한다. 인사평가 데이터는 조건에서 명시적으로 배제한다.
- [ ] 현황 확인

## 3. 세 안건 조합

세 안건은 축이 겹치지 않아야 한다. 2-2와 2-3(회의·보고), 2-3과 2-4(문서), 2-5와 2-6(프로그램 운영)은 서로 인접하므로 같은 세트에 넣지 않는다.

| 조합 | ① | ② | ③ | 참가자 감정 |
| --- | --- | --- | --- | --- |
| **A안(권장)** | 게시판 익명제 | 회의 30분 상한제 | 콘도 배정 규칙 | 내가 숨는다 / 내 시간을 지킨다 / 내가 받는다 |
| B안 | 게시판 익명제 | 대면 보고 폐지 | 멘토링 짝 정하기 | 내가 숨는다 / 내 일이 바뀐다 / 내가 맡겨진다 |

A안을 권하는 이유는 세 감정이 가장 멀리 떨어져 있어 안건 선택 화면에서 실제로 선택이 갈리기 때문이다(`AX_Day_2026_Boardroom_Plan.md` 5절은 세 안건의 `핵심 갈등`과 `성격`이 서로 다를 것을 요구한다).

## 부록 B. 안건 하나를 확정하면 필요한 작업
