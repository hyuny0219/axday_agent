# 임원 에이전트 고도화 — 튜닝 라운드 v12 (T110, 두 단계 설득)

- 대상: `server/prompts/common.ts`(`REACTIONS_FIRST_PASS_RULE`·`FOLLOWUP_ANSWERED_RULE`·`VOTE_UNANSWERED_RULE` 신설, 회의 기록 블록에 "추가 질문 답변" 줄), `server/handlers/round.ts`·`vote.ts`(요청 스키마에 `followUpAnswered` 선택 필드, 단계 지시에 새 규칙 연결), `server/providers/mock.ts`(새 규칙 흉내), `server/prompts/version.ts`(v11 → v12), `scripts/eval-set.json`·`eval-set-run.ts`("답변 안 함" 2케이스)
- 평가 세트: `scripts/eval-set.json` 22케이스 = 기존 20케이스 + 안건별 "답변 안 함" 1케이스씩
- provider: **mock**(`MODEL_PROVIDER=mock`) · modelId: mock-model. **live 실측은 하지 않았다.** 사용자 승인 뒤 `npx tsx scripts/eval-set-run.ts --out docs/eval/tuning-v12-after.jsonl`로 돌린다.

## 왜 v12 라운드인가

2026-10-09 사용자 지시: "처음 추천문구를 선택해서 의견전달했을 때 전부 설득당하면 재의견을 내지 않아도 성공하기 때문에, 난이도 조절을 해줘." scripted는 규칙표(`voteRules`)가 첫 반응에서 곧바로 찬성으로 바꿔, 추천 문구를 모두 고르면 추가 질문에 답하지 않아도 가결됐다. live도 같은 문제가 생길 수 있어 프롬프트 규칙으로 막는다.

## 무엇을 고쳤는가

- **첫 반응(REACTIONS)**: 참가자 조건이 우려를 충분히 풀어도 stance는 `UNDECIDED`(고민 중)까지만, 참가자 쪽 확정은 추가 질문에 답한 뒤. 발언에는 "조건은 좋습니다. 하나만 더 묻겠습니다"에 해당하는 뜻을 쉬운 말로 담는다. 위의 "첫 의견부터 방향을 밝히라"는 stance 지침보다 우선한다. 처음부터 참가자와 같은 편이던 임원은 그대로다.
- **후속(FOLLOWUP)**: 답을 받았으니 조건과 답이 우려를 풀면 참가자 쪽으로 확정해도 된다. 회의 기록에 "추가 질문 답변: 있음".
- **표결(VOTE)**: `followUpAnswered`가 `false`일 때만 "추가 질문 답변: 없음"과 함께 규칙이 붙는다 — 확정하지 않았던 임원은 참가자 쪽으로 던지지 않고 처음 입장대로(찬성 참가자면 반대표) 표결한다. 필드가 없으면(기존 요청) 규칙이 붙지 않아 동작이 그대로다.
- 정답표(어느 임원이 어느 조건에 넘어오는지)는 넣지 않았다. 임원이 매번 자기 관점으로 판단한다는 원칙(`EXEC_DECISION_RULE`)은 그대로다.

## live 실측 계획 (승인 후)

1. 22케이스 전수(264행)를 실행해 v11 대비 비교한다.
2. 확인할 것: (a) REACTIONS에서 조건을 충족한 임원의 stance가 `UNDECIDED`인 비율, (b) "답변 안 함" 두 케이스의 VOTE가 CEO를 뺀 세 임원 중 몇 명이 반대인지, (c) 기존 20케이스의 표 분포가 v11과 같은지(필드를 싣지 않으므로 같아야 한다), (d) 쉬운 말·존댓말 지표가 v11 수준인지.
3. 기대와 다르면 규칙 문구만 손본다(정답표는 넣지 않는다).
