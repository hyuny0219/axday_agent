# 임원 에이전트 고도화 — 튜닝 라운드 v5 (T54, 인용을 자료명으로 교체)

- 대상: `server/prompts/common.ts`(가드레일 인용 지시, `formatEvidence` 자료 목록 순서), `server/prompts/version.ts`(v4 → v5)
- 평가 세트: `scripts/eval-set.json`(12케이스) · 실행기 `scripts/eval-set-run.ts`
- provider: anthropic · modelId: claude-sonnet-5
- before 기록: `docs/eval/tuning-v5-before.jsonl`(promptVersion=v4, 144행) — T52(참가자 화면에서 E1~E4 표기 제거)가 이미 반영된 상태에서 v4 프롬프트로 다시 측정한 기준선. 이전에 커밋됐던 같은 이름의 파일은 provider_error로 84/144행이 실패해 이번에 다시 실행해 덮어썼다(원인은 이 라운드의 변경과 무관 — 재실행 시 0건 실패로 재현됨).
- after 기록: `docs/eval/tuning-v5-after.jsonl`(promptVersion=v5, 144행)

## 왜 v5 라운드를 돌았는가

T52가 참가자 화면에서 `E1`~`E4` 카드 ID 표기를 없앴는데도, 공통 가드레일은 여전히 "모든 주장에는 제공된 근거 카드 ID(예: E1)를 인용하십시오"라고 지시해 임원 발언 문장에 "…미정입니다(E4)"처럼 화면에 없는 기호가 그대로 나왔다.

## 무엇을 고쳤는가

- `buildCommonGuardrails()`의 인용 지시를 "자료 이름을 문장 속에서 그대로 인용하고, 자료 ID(E1 등)는 evidenceIds 필드에만 넣으라"로 바꿨다. 응답 스키마의 `evidenceIds`(`server/validate.ts`)는 그대로 두어 ID로만 채우게 한다 — 검증·기록용 필드는 건드리지 않는다.
- `formatEvidence()`가 자료 목록을 보여줄 때 `자료명 [ID: E1]` 순서로 바꿔, 모델이 문장에는 이름을, 스키마 필드에는 ID를 쓰도록 순서로도 유도했다.
- `PROMPT_VERSION`을 v4 → v5로 올렸다.
- `scripts/eval-set-run.ts`에 `findEvidenceIdMentions()`를 추가해 `message`·`reason` 필드에 `E\d` 패턴이 남는지 코드로 집계한다(`--check`가 기존 존댓말 위반 집계와 함께 이 수치도 찍는다).

## CAIO "연계·운영" 두 단어 저하에 대한 설명

before/after 모두 CAIO 역할 프롬프트(`server/prompts/roles/caio.ts`)는 바뀌지 않았다. 좁게 "연계"·"운영" 두 단어만 셀 때는 24/36 → 14/36으로 줄었지만, 독립 재실행(같은 v5 프롬프트로 한 번 더 144호출) 결과도 17/36으로 비슷해 이번 변경이 일으킨 재현 가능한 경향으로 보인다. 원인으로 보이는 것은 어휘 선택이 아니라 **문장 길이 예산**이다: 자료 인용이 `E4`(2자)에서 `정보보호 메모`(6자) 같은 자료명으로 바뀌면서 message(120자)·reason(160자) 한도 안에서 "운영 리스크가 큽니다" 같은 부연에 쓸 여지가 줄었다(실측 최대 길이도 오히려 더 짧아졌다 — 위 표). 실제 응답을 보면 CAIO는 여전히 기술적 구현 가능성·데이터 준비 상태·체계 연계·운영 부담이라는 같은 판단 기준을 쓰고 있고("정보보호 메모상 추적 권한·로그 설계가 미완이라 기술적으로 지금 바로 구현은 어렵습니다" 등), 표현만 "운영"·"연계" 대신 "구현"·"설계"·"체계" 쪽으로 옮겨갔다. 그래서 역할 프롬프트의 핵심 어휘(기술·구현·데이터·체계·부담·운영·연계·설계) 중 하나 이상을 넓게 세면 before·after 모두 36/36으로 동일하다 — 판단 기준 자체의 후퇴는 아니라고 본다. 다만 표현이 좁아진 경향은 실재하므로, 이후 문장 길이 한도 조정이 필요해지면 참고할 관측값으로 남긴다.

## 라운드 판정

완료 기준 "자료 밖 사실 0건 유지, 근거 미인용 0건 유지, 발언 문장에 `E\d` 패턴이 남지 않음, 역할 키워드·지연·문장 길이 악화 없음" — 충족. `E\d` 패턴은 142건에서 0건으로 없어졌고(이번 라운드의 목표), 근거 미인용·검증 실패·8초 초과·표결 분포(무조건 찬성·반대 역할 없음)는 모두 v4와 동일하게 유지되며, 지연·문장 길이는 오히려 개선됐다. CAIO의 좁은 두 단어 빈도만 관측 가능한 저하가 있었으나 역할 판단 기준을 담는 넓은 어휘 집합으로 보면 유지되고, 원인도 인용 방식 변경에 따른 문장 길이 예산 재배분으로 설명된다(원인은 이 라운드가 만든 것이지만, 판단 기준의 후퇴는 아니다). 카드의 크기(S)에 맞춰 이 한 라운드로 마친다.
