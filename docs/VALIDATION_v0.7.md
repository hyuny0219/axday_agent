# v0.7 변경 확인

2026-09-09 · 이번 개정은 설명·범위·창 실행·카드 표시 정리다. v0.6 원본과 대조해 ①② 시나리오 전체, ③ 표결 규칙 및 대표 경로 표가 변경되지 않았음을 확인했다. 규칙 전수 검증은 다시 수행하지 않았으며 기존 [v0.6 검증](VALIDATION_v0.6.md)의320조합·35대표 경로가 적용된다.

| 시나리오 | 찬성 한 표로 가결 성립 | 반대 한 표로 부결 성립 | 원안 승인 |
| --- | --- | --- | --- |
| ① | 있음 | 있음 | 없음 |
| ② | 있음 | 있음 | 없음 |
| ③ | 있음 | 없음(현재 규칙) | 있음 |

③에도 참가자 YES면 가결, NO/HOLD면 보류가 되는 원안 경로가 있어 반대의 영향이 없다는 뜻은 아니다. P1+P4는 VALIDATE_FIRST이므로 최종 표시가 검증안(확대 재심의)인 것은 기존 정규화 규칙에서 도출된다.

문서 내부 링크와 기존 규칙 유지 여부를 확인했다. 두 모니터 창 실행·전체화면·팝업 차단·P1+P4 실제 화면·배열 고정·공개 selector 검수는 구현 후 완료 조건이며 이번에 앱으로 시험한 결과가 아니다.
